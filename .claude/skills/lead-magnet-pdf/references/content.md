# התוכן - `content.json`

**ארבעה עמודי A4. 500-700 מילים.** מדריך ארוך יותר לא נקרא; קצר יותר לא שווה מייל.

## המבנה

```jsonc
{
  "title": "חמש משימות שאתם עושים ביד, ולא צריך",   // 6-10 מילים. אומר מה יוצא לקורא מזה
  "hl_word_1": "ביד", "hl_word_2": "לא צריך",             // מילה/ביטוי מהכותרת שיודגשו (צבע ראשי / משני)
  "tag": "// מדריך קצר לבעלי עסקים",
  "lead": "2-3 משפטים: מה הבעיה, ומה יוצאים איתו",
  "site": "roei-ai.co.il",
  "learn": ["4 דברים שהקורא יקבל", "...", "...", "..."],
  "sections": [
    { "title": "01 - הבעיה, בשפה של הקורא", "body": "פסקה אחת-שתיים. 60-100 מילים" },
    { "title": "02 - השיטה / הבדיקה", "body": "פסקה קצרה",
      "steps": ["צעד 1", "צעד 2", "צעד 3"],                              // 3-5
      "metrics": [{ "value": "3", "label": "שאלות לכל משימה" }, ...] },   // 2-3. מספרים אמיתיים בלבד, אחרת [חסר: מספר]
    { "title": "03 - הפירוט / הדוגמאות", "body": "80-130 מילים. פסקאות מופרדות ב-\\n\\n" },
    { "title": "04 - מה עושים עם זה", "body": "60-100 מילים" },
    { "title": "05 - רשימת הבדיקה", "items": ["6-8 שורות שאפשר לסמן"] }
  ],
  "insight": "משפט אחד. הדבר האחד לקחת מהמדריך",
  "cta": { "title": "השאלה/ההזמנה", "text": "מה ההצעה, במשפט", "button": "טקסט הכפתור ←", "button_url": "https://wa.me/972...?text=...",   // לאן הכפתור מוביל. קישור לחיץ ב-PDF
           "meta": ["שם", "טלפון", "אתר"] }
}
```

## כללי הכתיבה

- **פסקאות זורמות בגוף.** בולטים רק ב-`steps`, `learn`, `items`.
- **הווה פעיל, דוגמאות ספציפיות.** "לענות ללקוח ששאל על שעות פתיחה", לא "מענה ללקוחות".
- **בקול של `voice.md`** - אורך משפט, פנייה, מילים שהוא לא אומר.
- **דו-מגדרי** - מדריך נקרא בידי גברים ונשים ("אתם" / ניסוח ניטרלי).
- **בלי מקפים ארוכים.** מקף רגיל.
- **בלי:** מטורף, קסם, מהפכה, "המובילים", ובלי סיכומים כמו "התוצאה:" - מתארים ועוצרים.
- **`[חסר: ...]`** על כל מספר או עובדה שאין בקונטקסט. יופיע בצהוב במדריך עד שהמשתמש ימלא.

## מה לא נכנס

- סטטיסטיקות בלי מקור ("80% מהעסקים...").
- הבטחות ("תחסכו 10 שעות בשבוע") - אלא אם זה מספר מהעסק עצמו.
- מכירה בעמודים 1-3. המכירה היחידה היא ה-CTA בעמוד 4.
